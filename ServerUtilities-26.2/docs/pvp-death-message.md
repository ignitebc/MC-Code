# 플레이어 간 교전 사망 문구

표시 문구는 다음과 같습니다. 이름 뒤의 공백을 포함합니다.

```text
{사망한 플레이어명} 님이 누군가에게 살해당했습니다.
```

`mixin/ServerPlayerDeathMixin.java`에서 바닐라 사망 메시지 생성 호출의 결과를 교체합니다.
다른 서버 플레이어가 직접 가한 피해와 그 플레이어가 발사한 화살·TACZ 탄환 등 투사체 피해를 포함합니다.
환경 피해라도 바닐라의 처치 기여 판정에 다른 플레이어가 남아 있으면 같은 문구를 사용합니다.
자기 자신이 원인인 피해와 플레이어 교전 판정이 없는 사망에는 기존 사망 문구를 사용합니다.

사망 화면·채팅이 같은 문구를 사용하며 `show_death_messages`와 팀별 사망 공지 공개 범위는 바닐라 흐름을 따릅니다.
아이템 2슬롯 손실·배낭 내용물 삭제·보존권 처리·유품 상자 설치는 기존 사망 드롭 직전 경로에서 별도로 유지합니다.

## 빌드와 확인

Minecraft 26.2 / Java 25 환경에서 `ServerUtilities-26.2` 폴더의 다음 명령을 실행합니다.

```powershell
.\gradlew.bat build
```

소스와 Minecraft 26.2의 호출 위치를 정적으로 대조했습니다.
