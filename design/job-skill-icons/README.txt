직업·스킬·비트코인 이미지 자료 (2026-10-08 갱신)

향후 제작 기본값
- 아이템으로 표시되는 텍스처의 최종 적용 해상도는 기본 64 x 64이다.
- 직업·일반스킬·하이퍼스킬·상태 효과 등 UI 전용 아이콘과 그 외 정사각형 텍스처는 기본 256 x 256이다. 동일 그림을 공유해도 용도별 해상도로 각각 내보낸다.
- 큰 해상도로 생성된 이미지는 그림과 비율을 유지하여 고품질 축소 후 적용한다. 투명 아이콘의 알파와 불투명 모델 표면의 불투명 상태를 각각 보존한다.
- 게임 내 표시 크기·모델 크기·UV는 별도 요청 없이 변경하지 않는다. 사용자 지정 해상도와 아틀라스·애니메이션 등 별도 규격은 예외로 한다.

보관 파일
- gallery.html: 적용 중인 PNG 50개와 작은 크기 표시를 비교하는 갤러리
- job-prompts.txt: 채택한 직업 이미지 8종의 생성 프롬프트
- skill-prompts.json: 일반 스킬 40종과 비트코인 2종의 생성 프롬프트
- assets.json: 저장소 루트 기준 리소스 경로, 크기, 용량, SHA-256 목록
- 이미지 생성 방식: built-in image_gen
- 직업·일반 스킬의 배포 PNG는 원본을 256 x 256으로 고품질 bicubic 리샘플링하고 32비트 RGBA 투명도를 유지했다. 프롬프트 파일은 원본 생성 기록이다.
- 실제 PNG는 각 모드의 src/main/resources에서 관리하며 이 폴더에 중복 보관하지 않는다.

반영된 기능
- 32f1bbd4: 직업 목록·상세, 일반 스킬 트리·상세, 레벨업 알림 이미지 적용
- 89a7ae74: 비트코인 이미지와 입체 아이템 모델 적용
- 일반 스킬 40개 효과 계열을 490개 단계 정의에 연결한다.
- 같은 효과 I~X는 이미지를 공유하고 1~10 숫자 배지를 표시한다.
- 기존 잠금·구매·활성 상태와 사용자 정의 아이콘 대체 표시를 유지한다.
- 기존 하이퍼 스킬 전용 이미지는 유지한다.
- 화약충전은 화약 주머니, 화력 증강은 탄창·탄약·화살 조합의 신규 이미지로 교체했다.
- 신규 아이콘 2종의 실제 생성 프롬프트는 skill-prompts.json에 반영했다.
- Bitcoin ID advancednetherite:bitcoin과 보상·거래·저장 로직은 유지한다.
- GUI는 item/generated 모델, 그 외 표시 문맥은 두께 있는 동전 모델을 사용한다.
- Fabric 데이터 생성 코드에도 표시 문맥에 따른 모델 분기를 반영했다.

확인 범위와 제한
- 현재 프로젝트의 실제 Minecraft 설정은 26.2이며 작업 브랜치는 26.3이다.
- 직업 8종·일반 스킬 40종은 256 x 256이며, 비트코인 아이템·입체 모델 표면 PNG 2종은 64 x 64다. 적용 PNG 50개 합계는 4,880,612바이트(약 4.65 MiB)다.
- 비트코인 PNG 2종은 디자인·모델·UV를 유지해 6,010,945바이트에서 21,845바이트(약 21.33 KiB)로 줄였다.
- 직업·일반 스킬 48종의 PNG 합계는 70,339,020바이트(약 67.08 MiB)에서 4,858,767바이트(약 4.63 MiB)로 약 93.09% 감소했다.
- 이 48종의 게임 내 표시 크기는 기존 18~28 논리 픽셀을 유지한다.
- 48종의 RGBA 4바이트 픽셀 데이터는 약 287.94 MiB에서 12 MiB로 줄어든다. 밉맵·드라이버 비용을 제외한 계산값이며 실제 게임 메모리 측정값이 아니다.
- 48종 모두 256 x 256, 32비트 RGBA, 투명 모서리를 확인했고 assets.json의 해상도·용량·SHA-256과 일치한다. 대표 이미지의 축소 결과를 확인했으며 게임 내 GUI 배율별 품질은 미확인이다.
- bitcoin_face.png는 전체 alpha=255로 불투명하다.
- bitcoin.png는 중앙 alpha=253으로 본체에 미세한 투명도가 남아 있다.
- 갤러리는 브라우저 축소 예시이며 실제 게임 렌더 결과가 아니다.
- 사용자 요청에 따라 Java 25로 JobsPlusRemastered-26.2의 :fabric:build --rerun-tasks 빌드 성공. fabric:test는 NO-SOURCE이며 별도 테스트·린트·데이터 생성·게임 실행은 미실행이다.
- 배포 JAR 내부의 256px 아이콘 48종과 리소스 해시 일치를 확인하고 Build_File-26.2/build_files의 Jobs+ JAR만 교체했다. 다른 모듈 JAR 10개는 해시가 그대로다.
- 앞선 갱신에서는 사냥꾼 PNG 2종과 직업·일반 스킬 PNG 48종을 적용했다. 이번 갱신은 비트코인 PNG 2종을 64px로 축소하고 용도별 이미지 제작 기준을 기록했다.
- 비트코인 축소 커밋 시점에는 후속 빌드·배포 JAR 교체 전이며, 게임 내 품질은 미검증이다.
