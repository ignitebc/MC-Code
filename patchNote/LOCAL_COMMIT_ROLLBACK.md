## 롤백 의존 관계

- TACZ 변경은 서버 공통 모듈 변경과 별개입니다. 코드·리소스를 되돌리면 아이템 안내 문서도 그 상태에 맞춰 되돌립니다.
- 서버 기능 커밋 5~7은 기반 커밋 4가 필요합니다. 각 기능의 새 구현과 이전 모드에서의 제거를 같은 커밋에 묶었습니다.
- 서버 공통 모듈을 완전히 제거하려면 수집 연결 8 → 사망 7 → 밸런스 6 → 전투 5 → 기반 4 순서로 되돌립니다. 수집 실패 복구 9는 유지할 수 있습니다. 관련 운영 문서는 결과에 맞춰 갱신합니다.
- 모든 이번 변경을 이전 상태로 되돌릴 때는 문서 커밋부터 1번까지 역순으로 되돌립니다. 이 문서 작성 시 실제 revert는 실행하지 않았습니다.
- 공통 진입점·Mixin 등록 파일을 여러 커밋이 수정하므로 일부만 선택해 되돌릴 때 문맥 충돌이 생길 수 있습니다. 그 경우 선택한 기능의 이벤트 등록·Mixin 항목·기존 모드 구현이 한 쌍으로 맞는지 확인합니다.
- 기능 이관 커밋의 롤백은 이전 모드의 구현을 복원합니다. 운영 중 기능을 잠시 끄려면 [개별 설정](../ServerUtilities-26.2/README.md)을 사용합니다.

## 월드와 JAR 교체

1. Server Utilities 제거 전 `sleep.enabled=false`와 `/serverutilities reload`로 수면 규칙을 복원합니다.
2. 서버를 종료한 뒤 선택한 소스 조합에서 빌드한 Jobs+·Advanced Netherite·Server Utilities JAR을 함께 교체합니다.
3. 사망 보존 상태는 기존 `JobsPlusDeathItemProtected` 저장 키를 유지하므로 이를 지원하는 이전 Jobs+와 호환됩니다. 사망 화면 재접속은 실제 서버에서 확인해야 합니다.
4. 이미 삭제된 아이템은 코드 롤백만으로 복원되지 않습니다.

## 검증 기록

- 구현 단계에서 최종 조합의 Server Utilities·Jobs+·Advanced Netherite 빌드 통과.
- 설정·수면 복원 검사 28개, 수집기 검사 8개 통과.
- Fabric 개발 서버의 설정 초기화 실행에서 실제 게임 클래스의 네 개 Mixin 적용 확인.
- 커밋 분할 단계에서는 각 커밋의 파일·참조·Mixin 등록 구성과 최종 코드 일치 및 공백을 검사. 각 중간 커밋의 전체 빌드를 새로 수행한 것은 아님.
- TACZ 탄약상자 변경은 이전 정적 검사·간이 API 대역 회귀 검사로 확인했으며 실제 TACZ 게임 실행 검증은 미수행.
- 전체 11개 모드 수집·다인 접속·사망 후 재접속·전체 모드 조합 실행 검증은 미수행.
