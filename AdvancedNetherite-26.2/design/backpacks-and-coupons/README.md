# 배낭과 비트코인 획득 확률 쿠폰

`26.3` 브랜치의 기존 Minecraft 26.2 / Fabric / Java 25 설정을 사용한다.

## 아이템

| 아이템 ID (`advancednetherite:`) | 디자인 | 동작 |
| --- | --- | --- |
| `backpack_level_1` | 소형 카키 캔버스, I 표식 | 일반 인벤토리 +4칸, 핫바 포함 총 40칸 |
| `backpack_level_2` | 중형 샌드색 전술 배낭, II 표식 | 일반 인벤토리 +8칸, 핫바 포함 총 44칸 |
| `backpack_level_3` | 대형 올리브 위장 배낭, III 표식 | 일반 인벤토리 +12칸, 핫바 포함 총 48칸 |
| `bitcoin_double_coupon` | 청록색 티켓, 비트코인 문양, 2X | 10분간 직업 비트코인 획득 확률 ×2 |
| `bitcoin_triple_coupon` | 보라색·금색 티켓, 비트코인 문양, 3X | 10분간 직업 비트코인 획득 확률 ×3 |

배낭 원본과 쿠폰의 이전 디자인은 `source/`, 당시 제작 사양은 `prompts.json`에 있다.
게임용 PNG는 `Common/src/main/resources/assets/advancednetherite/textures/item/`의
같은 이름 파일이다. 배낭 3종은 기존 32×32 RGBA와 최근접 보간·이진 알파를 유지한다.
2026-10-08 재제작한 비트코인 쿠폰 2종의 아이템 텍스처는 64×64 RGBA이며, 고품질 Bicubic 보간으로
축소하고 투명 배경을 유지했다. 쿠폰 상태 효과 아이콘은 같은 새 디자인의 256×256 RGBA를 사용한다.
현재 쿠폰의 제작 사양과 미리보기는 저장소 루트의
[`design/item-icons/`](../../../design/item-icons/README.txt)에 있다.

## 배낭 사용과 저장

- 생존 인벤토리(E) 오른쪽에 가방 장착 슬롯과 4열의 추가 인벤토리가 표시된다.
- 가방을 장착 슬롯에 놓거나 Shift 클릭으로 장착한다. 핫바는 9칸을 유지한다.
- 장착 중에만 등급별 4/8/12칸에 아이템을 넣을 수 있다.
- 내용물이 있어도 가방을 해제하거나 교체할 수 있다. 새 가방을 커서에 든 채 장착 슬롯을
  클릭하거나 숫자키로 교환하면 내용물은 새 가방의 추가 칸에 남는다.
- 1렙 → 3렙 교체는 기존 내용물과 위치를 유지한다. 3렙 → 1렙 교체는 유지되는 4칸의
  스택 여유와 빈 칸에 초과 슬롯의 물건을 먼저 넣고, 들어가지 않는 나머지만 바닥에 떨어뜨린다.
  일반 인벤토리의 빈 칸으로 자동 이동시키지 않는다.
- 가방을 먼저 집어 들거나 Shift·숫자키·Q로 해제하면 용량이 0칸이 되어 모든 내용물을
  바닥에 떨어뜨린다. 내용물을 유지하며 교체하려면 새 가방으로 직접 교환한다.
- 일반 인벤토리가 차면 자동 획득과 상자·제작 결과의 Shift 이동이 추가 칸을 사용한다.
- 추가 칸은 플레이어 저장 데이터에 함께 저장된다. 별도 가방 내부 아이템 데이터나
  별도 보관함 창을 만들지 않는다.
- 기존 사망 드롭·보존권·인벤토리 유지 규칙이 가방과 추가 칸에도 적용된다.
- Server Utilities 사망 손실은 비어 있지 않은 서로 다른 슬롯을 무작위로 최대 2개 선택해
  각 스택 전체를 삭제한다. 추가 칸도 추첨 대상이며, 소지품이 1슬롯뿐이면 그 슬롯만 삭제한다.
- 장착한 가방이 사망 손실로 선택되면 추가 12칸의 내용물도 드롭 없이 전부 삭제한다.
  함께 비워진 칸은 두 번째 선택으로 세지 않고 남은 소지품에서 다시 뽑는다.
  일반 인벤토리의 여분 가방이 선택되면 현재 장착 가방의 내용물은 영향을 받지 않는다.
- 명령어가 가방만 강제 제거한 경우, 남아 있는 추가 칸의 물건은 꺼낼 수 있다.
  가방 없이 새로운 물건을 넣을 수는 없다.
- 제작책 재료와 반환 공간, 총기 탄약·제작 재료, 도감의 보유 재료 수에 추가 칸을 반영한다.
- 크리에이티브의 아이템 선택 화면은 기존 슬롯을 유지한다. 가방 장착·관리는 생존 모드에서 한다.

## 쿠폰 규칙

- 기존 `bitcoin_double_coupon`의 지급량 증가를 획득 확률 증가로 변경했다.
- 직업 비트코인 보상의 실제 확률 판정에만 배율을 적용한다. 1회 지급 수량은 그대로다.
- 예: 기본 확률 1% → 2배 쿠폰 2%, 3배 쿠폰 3%. 최종 확률은 100%를 넘지 않는다.
- 같은 배율을 다시 사용하면 10분 연장된다. 다른 배율의 비트코인 쿠폰이 활성화되어 있으면
  새 쿠폰을 소비하지 않는다. 2배와 3배가 곱해져 6배가 되지 않는다.
- 경험치 쿠폰은 별도 효과이므로 함께 사용할 수 있다.
- 만료 시각은 실제 시간 기준이며 로그아웃·사망·서버 종료 중에도 시간이 흐른다.
- 기존 2배 쿠폰의 만료 시각을 유지한다. 기존 저장 데이터에 없는 3배 만료 시각은 0으로 읽는다.

## 적용 모듈과 검증

클라이언트와 서버에 Advanced Netherite, Jobs+, TACZ의 변경 JAR을 함께 적용한다.
새 아이템은 Advanced Netherite 크리에이티브 탭과 `/give`로 확인할 수 있다.
이번 변경에는 제작 비용·상점 가격·상자 등장 확률을 추가하지 않았다.

리소스 JSON, PNG 규격, 변경 공백, Minecraft 26.2 바이너리의 Mixin 대상 메서드를 정적으로 대조했다.

저장소 루트에서 프로젝트 표준 전체 빌드:

```bash
python Build_File-26.2/collect_fabric_jars.py
```

게임 확인용 명령:

```text
/give @s advancednetherite:backpack_level_1
/give @s advancednetherite:backpack_level_2
/give @s advancednetherite:backpack_level_3
/give @s advancednetherite:bitcoin_double_coupon
/give @s advancednetherite:bitcoin_triple_coupon
```
