# 등급·제작식 기준

기준: 2026-09-22 / MC-Code `26.3` / TaCZ 기본 총기팩

총기 76종, 부착물 99종, 탄약 18종의 등급을 정하는 방법과, 등급에서 제작식 재료를 뽑는 방법을 적습니다.

## 정본 위치

| 대상 | 정본 |
|---|---|
| 등급표 | `tools/apply_tier_colors.py` 의 `GUNS` / `ATTACHMENTS` / `AMMO` |
| 이름 색 | 위 표에서 `python tools/apply_tier_colors.py` 로 생성. 직접 고치지 않습니다 |
| 제작식 | `data/tacz/recipe/{gun,attachments,ammo}` |

등급표에 없는 항목이 있으면 `apply_tier_colors.py` 가 실행을 멈춥니다. 총기나 부착물을 추가하면 표에 먼저 넣어야 합니다.

## 등급 색

F 부터 S 까지 연두, 하늘, 파랑, 보라, 노랑, 빨강, 주황입니다.

## 1. 총기 등급 판정

### 판정 축

등급 축은 지어낸 것이 아니라 기존 배정에서 역산했습니다. 각 지표와 등급의 상관계수를 재면 아래와 같습니다.

| 지표 | 상관계수 | 채택 |
|---|---:|---|
| 무게(체급) | +0.77 | O |
| 지속 DPS | +0.66 | O |
| 순간 DPS | +0.56 | O |
| 관통 수 | +0.44 | O |
| 유효사거리 | +0.35 | O |
| 방어구 무시 | +0.34 | O |
| 한 발 피해 | +0.33 | O |
| 재장전 시간 | −0.36 | 체급에 포함 |
| 헤드샷 배율 | −0.00 | X |
| 장탄수 | −0.00 | X |
| 조준 산포 | −0.07 | X |
| 반동 | −0.14 | X |

**이 팩의 총기 등급은 체급 x 화력입니다.** 반동, 조준 산포, 장탄수, 헤드샷 배율은 등급 축이 아닙니다. 다루기 쉬운 총이라고 등급이 오르지 않습니다.

### 가중치

| 축 | 구성 | 가중 |
|---|---|---:|
| 체급 | 무게 | 0.31 |
| 화력 | 지속 DPS 0.60 + 순간 DPS 0.40 | 0.27 |
| 관통력 | 방어구 무시 0.55 + 관통 수 0.45 | 0.16 |
| 사거리 | 유효사거리 0.70 + 탄 도달거리 0.30 | 0.13 |
| 단발 위력 | 한 발 실효 피해 | 0.13 |

각 지표는 76종 안의 순위 백분위로 정규화합니다. 미니건 무게 15.5 같은 극단값이 척도를 무너뜨리지 않게 하기 위해서입니다.

### 계산 규칙

- **실효 피해**는 다이아몬드 풀세트(방어 20, 강도 8) 기준입니다. 바닐라 감쇄식을 그대로 쓰고, 방어구 무시 비율만큼은 전량 관통으로 칩니다.
- **지속 DPS** 는 재장전을 포함한 한 주기 평균입니다. `장탄 / (장탄 / 초당발수 + 재장전 쿨다운)`.
- **볼트액션 총기**는 `bolt_action_time` 으로 실제 연사를 제한합니다. AWM 171 → 67 RPM, M95 151 → 42 RPM.
- **폭발 전용 무기**(M320, RPG-7)는 거리별 피해표가 없으므로 사거리를 `폭발 반경 x 10` 으로 대신합니다.
- 미니건은 `reload.type` 이 `inventory` 인 유일한 총기이며 `ammo_amount` 가 없어 코드 기본값 30 을 씁니다.

## 2. 부착물 등급 판정

조준경과 탄약개조는 바꾸는 값이 아예 달라 전역 비교가 뜻이 없습니다. **같은 종류 안에서만** 순위를 매깁니다.

역산한 축: 조준 시간 페널티 −0.51(가장 강함), 반동 감소 +0.40, 조준 산포 감소 +0.32, 은신 산포 +0.24, 소음 감소 +0.22, 무게 +0.21. **부착물 등급은 효과 크기와 그 대가(무게·조준 지연)를 함께 봅니다.**

| 종류 | 평가 지표 |
|---|---|
| 조준기 | 배율 0.40, 조준 산포 0.35, 조준 시간 −0.25 |
| 조준경 | 배율 0.45, 조준 산포 0.30, 조준 시간 −0.25 |
| 레이저 | 비조준 산포 0.45, 은신 산포 0.40, 조준 시간 −0.15 |
| 소음기 | 소음 0.35, 사거리 0.20, 헤드샷 0.20, 조준 산포 0.15, 탄속 0.10 |
| 소염기 | 반동 0.60, 비조준 산포 0.25, 조준 산포 0.15 |
| 초크 | 비조준 산포 0.60, 사거리 0.40 |
| 총열 | 사거리 0.60, 피해 0.40 |
| 총검 | 근접 피해 1.00 |
| 개머리판 | 반동 0.55, 조준 산포 0.30, 조준 시간 −0.15 |
| 손잡이 | 반동 0.50, 비조준 산포 0.35, 조준 시간 −0.15 |
| 확장 탄창 | 증가 단계 1.00 |
| 탄약 개조 | 피해 0.30, 방어구 무시 0.25, 관통 0.20, 헤드샷 0.15, 폭발 0.10 |

보정치는 `AttachmentPropertyManager.eval` 과 같은 식으로 계산합니다. `결과 = (기준 + addend) x (1 + percent) x multiplier`. 조건식(`function`)은 정적으로 풀지 않고 건너뜁니다.

## 4. 제작식 재료

### 난이도 계수

재료 1 개의 획득 난이도를 철 1 개 = 1.0 으로 둔 상대값입니다. 개수 산출과 등급 검증에만 쓰는 내부 값이며 게임에 노출되지 않습니다.

| 재료 | 계수 | 재료 | 계수 |
|---|---:|---|---:|
| 점토 | 0.15 | 자수정 | 1.8 |
| 레드스톤 | 0.30 | 금 | 2.0 |
| 양털 | 0.30 | 흑요석 | 2.5 |
| 석탄 | 0.40 | 프리즈마린 크리스탈 | 2.5 |
| 가죽 | 0.50 | 블레이즈 가루 | 2.5 |
| 유리 | 0.50 | 블레이즈 막대 | 5.0 |
| 구리 | 0.60 | 에메랄드 | 6.0 |
| 화약 | 0.80 | 다이아 | 8.0 |
| 꿀벌집 | 0.80 | 네더라이트 | 40.0 |
| 철 | 1.00 | | |
| 청금석 | 1.20 | | |
| 마그마 크림 | 1.20 | | |
| 발광석 | 1.50 | | |
| 석영 | 1.60 | | |

태그가 있는 재료는 태그로 씁니다. 유리는 `#c:glass_blocks`, 철은 `#c:ingots/iron` 형식입니다. 석탄과 이번에 들인 재료 6종은 바닐라 ID 를 직접 씁니다.

### 총기 재료 팔레트

등급이 재료 구성을 정합니다. 작업대 화면이 한 번에 보여 주는 8칸을 넘지 않게, 등급이 오르면 아래쪽 재료가 빠지고 위쪽 재료가 들어옵니다.

| 등급 | 재료 | 종수 |
|---|---|---:|
| F | 철, 구리, 석탄 | 3 |
| E | + 유리 | 4 |
| D | + 청금석 | 5 |
| C | + 금 | 6 |
| B | + 석영 | 7 |
| A | 철, 구리, 석탄, 유리, 금, 석영, 자수정, 에메랄드 (청금석 제외) | 8 |
| S | 철, 구리, 석탄, 금, 흑요석, 다이아, 블레이즈 막대, 네더라이트 | 8 |

개수는 철 대비 비율로 정하고, 총량은 `등급 기준 난이도 x 무게 편차` 에서 철을 역산합니다.

- 등급 기준 난이도: F 28, E 49, D 85, C 141, B 233, A 388, S 635. 한 등급당 약 1.67 배입니다.
- 무게 편차: 같은 등급 평균 무게 대비 비율을 절반으로 압축하고 0.75 ~ 1.30 배로 제한합니다. 같은 등급이라도 무거운 총이 재료를 더 먹습니다.
- 철 총합이 개편 전의 70% 가 되도록 비철 재료 비율을 한 번에 보정했습니다.
- Golden Deagle 만 이름이 곧 재료라 금을 따로 얹습니다.

### 부착물 재료 팔레트

부착물은 **기능이 재료를 정하고 등급이 개수를 정합니다.** 조준경과 손잡이가 같은 재료를 쓰면 안 되기 때문입니다.

| 종류 | 고정 재료 (철 대비 비율) |
|---|---|
| 조준기 | 유리 0.80, 레드스톤 1.20, 발광석 0.25 |
| 조준경 | 유리 0.60, 석영 0.45, 레드스톤 1.50, 발광석 0.20 |
| 레이저 | 레드스톤 2.20, 유리 0.50, 자수정 0.25 |
| 소음기 | 구리 0.80, 양털 1.20 |
| 소염기 | 마그마 크림 0.35, 금 0.25 |
| 초크 | 구리 0.90 |
| 총열 | 구리 0.50, 금 0.50 |
| 총검 | 석탄 0.70 |
| 개머리판 | 가죽 1.10, 슬라임볼 0.50 |
| 손잡이 | 가죽 1.20, 슬라임볼 0.40 |
| 확장 탄창 | 구리 0.90, 꿀벌집 0.30 |
| 탄약 개조 | 화약 1.50, 블레이즈 가루 0.35, 에메랄드 0.12 |

등급은 재료 하나를 더 얹습니다. 누적하지 않고 그 등급의 것만 씁니다.

| 등급 | 추가 재료 | 기준 난이도 |
|---|---|---:|
| F, E | 없음 | 6, 9 |
| D | 청금석 | 14 |
| C | 금 | 22 |
| B | 석영 | 34 |
| A | 자수정 | 52 |
| S | 프리즈마린 크리스탈(광학계) 또는 다이아(그 외) | 81 |

### 탄약 재료 팔레트

**탄약에는 반복 획득이 가능한 재료만 씁니다.** 계속 소모되므로 프리즈마린, 자수정, 다이아, 에메랄드는 넣지 않습니다.

| 구성 | 재료 | 적용 |
|---|---|---|
| 탄피 | 구리 | 전 탄종 |
| 추진제 | 화약 | 전 탄종 |
| 연료 | 석탄 | 전 탄종 |
| 주형 | 점토 | 전 탄종 |
| 탄두 강화 | 청금석 | C 이상 |
| 대구경 탄심 | 철 | A 이상 |
| 소이·폭발 | 블레이즈 가루 | S |

발당 단가와 1회 제작 발수를 등급이 정합니다.

| 등급 | 발당 단가 | 1회 제작 발수 |
|---|---:|---:|
| S | 5.00 | 8 |
| A | 1.60 | 16 |
| B | 0.80 | 32 |
| C | 0.55 | 32 |
| D | 0.40 | 48 |
| E | 0.25 | 48 |

한 발씩 쓰는 탄은 묶음을 따로 둡니다. `rpg_rocket` 4발, `40mm` 8발.

## 5. 총량

개편 전후로 **총 난이도는 유지**했습니다. 등급별로 재분배만 한 것이며 경제 규모는 그대로입니다.

| 구분 | 난이도 총합 |
|---|---:|
| 총기 76종 | 16,867 (유지) |
| 부착물 95종 | 3,197 (유지) |
| 탄약 18종 | 발당 단가 기준으로 재산정 |

철은 전체에서 30% 줄였고, 그만큼을 구리·석탄·유리와 등급 재료로 옮겼습니다. 재료 종류는 17종에서 24종이 되었습니다.

## 6. 알려진 문제

| 항목 | 내용 |
|---|---|
| `scope_standard_8x` | 색인이 `scope_scout` 의 data·display 를 가리킵니다. `scope_standard_8x_data.json` 은 읽히지 않는 고아 파일입니다 |
| 제작식 없는 부착물 4종 | `grip_cqr`(A), `laser_peq15`(B), `scope_aug_default`(F), `sight_p90`(F). 뒤 둘은 내장 부품이라 정상입니다 |
| `ammo_mod_hp` | 관통을 0 으로 버리는 설계라 측정 모델이 크게 깎습니다. 의도된 맞교환이면 현재 등급이 맞습니다 |
| SPAS-12, RPG-7 | 사거리·관통 축에서 크게 잃습니다. 광역 피해는 점수에 넣지 않았습니다 |

## 7. 다시 뽑는 방법

```
python tools/apply_tier_colors.py    # 등급표 -> 이름 색
```

등급을 옮기려면 `apply_tier_colors.py` 의 표에서 ID 를 다른 줄로 옮긴 뒤 다시 실행합니다. 제작식은 이 문서의 팔레트와 기준 난이도를 그대로 적용해 다시 계산합니다.

**검증 상태**: 수치 계산과 JSON 정합성만 확인했습니다. Gradle 빌드, 작업대 화면 표시, 인게임 제작은 미실행입니다.
