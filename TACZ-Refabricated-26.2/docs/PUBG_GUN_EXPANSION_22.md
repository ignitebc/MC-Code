# PUBG 신규 총기 22종 설계

기준: 2026-09-21 / MC-Code 26.3 / TaCZ 기본 총기팩

## 구현 원칙

- PUBG PC·콘솔 현행 무기 목록을 기준으로 합니다.
- PUBG 원본 모델·텍스처를 복사하지 않습니다. 공개된 외형을 참고해 블록 기반 Bedrock 모델과 절차적 재질을 새로 생성합니다.
- 수치는 PUBG의 상대적 특성을 유지하되 현재 서버 TaCZ 피해 스케일로 환산합니다.
- 모든 총은 동일한 복제 모델을 쓰지 않고 profile, 크기, 탄창 위치, 개머리판, 총열, 재질, 액세서리 위치를 별도로 가집니다.

## 자산 생성 구조

빌드 시 `generatePubgGunResources` 작업이 실행되어 `build/generated/pubg-guns`에 22종 전체 리소스를 생성하고, 해당 디렉터리를 main resources source set에 포함합니다. 따라서 JAR 내부에서는 기존 `assets/tacz/custom/tacz_default_gun` 경로와 동일하게 로드됩니다.

## 확인 필요

현재 변경은 소스 및 리소스 생성 로직까지 반영한 상태이며 Gradle 빌드와 인게임 검증은 수행하지 않았습니다. 특히 기존 애니메이션 골격을 재사용하므로 손 위치, 탄창 이동, 일부 총기의 특수 동작은 실제 게임에서 확인 후 미세 조정이 필요합니다.
