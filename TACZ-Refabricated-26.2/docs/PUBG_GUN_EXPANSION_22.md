# PUBG 신규 총기 22종 설계

기준: 2026-09-21 / MC-Code `26.3` / TaCZ 기본 총기팩

## 구현 원칙

- PUBG PC·콘솔 현행 무기 목록을 기준으로 하되, 기존 총기와 역할이 겹치는 G36C, Lynx AMR, S1897, S686, P92는 제외하고 M24를 포함해 22종을 만듭니다.
- PUBG 원본 모델·텍스처·음원은 복사하지 않습니다. 실총의 외형 특징을 참고해 블록 기반 모델과 텍스처를 새로 만듭니다.
- 22종의 리소스는 다른 총기와 똑같이 `src/main/resources/assets/tacz/custom/tacz_default_gun/` 아래 실제 파일로 들어 있습니다. 빌드 시점에 생성하지 않습니다.
- 피해량은 같은 탄종을 쓰는 기존 총기 사이에 끼워 넣어 정했습니다. PUBG의 절대 수치가 아니라 상대적 위치를 따릅니다.

## 특수 동작

| 총기 | 구현 |
|---|---|
| DBS | 신규 스크립트 `tacz:dbs_gun_logic`. 관형 탄창 잔탄이 홀수면 펌프 없이 다음 탄을 약실로 올리고, 짝수면 펌프 동작을 거칩니다. 그래서 두 발을 연달아 쏜 뒤 펌프질을 합니다. 약실 1발 + 탄창 13발로 14발입니다. 장전과 펌프 타이밍은 M870과 같습니다. |
| MG3 | 자동 모드가 660 RPM, 점사 모드 자리가 990 RPM입니다. 점사는 3발 묶음을 끊김 없이 이어 쏘도록(`continuous_shoot`, 0.18초 간격) 설정했습니다. 발사 모드 표시는 "점사"로 나옵니다. |
| VSS | `builtin_attachments`로 4배율 조준경과 소음기를 내장했습니다. 소음기 부착물은 굵은 소음기 통 안쪽에 숨겨 두어 소음 효과만 적용됩니다. 조준경·총구 슬롯은 열려 있지만 허용 태그가 없어 바꿔 달 수 없습니다. |
| Win94 | `builtin_attachments`로 2배율 조준경을 내장했습니다. Kar98k의 볼트액션·장전 동작을 씁니다. |
| Mk12, MG3, RPD | 양각대 표현으로 엎드릴 때 반동 배율을 0.25~0.3으로 낮췄습니다(다른 총은 0.5). |
| Mk47 Mutant | 자동사격이 없고 2점사와 단발만 있습니다. |

## 외형 제작 구조

`tools/pubg_guns/` 의 파이썬 스크립트로 만듭니다. 수치는 `specs.py`, 외형은 `guns_*.py`, 부품 모양은 `parts.py`에 있습니다.

```
python tools/pubg_guns/build.py            # 22종 전부 다시 만들고 정합성 검사
python tools/pubg_guns/build.py m24 vss    # 일부만
python tools/pubg_guns/preview.py out.png guns_dmr:m24   # 파일을 쓰지 않고 모양만 확인
python tools/apply_tier_colors.py          # 등급 색 다시 적용
```

- 각 총기는 베이스 총기의 뼈대(이름·부모·피벗)를 그대로 복사하고 큐브만 새로 올립니다. 그래서 베이스의 애니메이션·상태 머신·손 위치·시점 뼈(`idle_view`, `iron_view`, `fixed`, `ground`, `refit_view`)를 그대로 씁니다.
- 손잡이·탄창·핸드가드 위치를 베이스 총기와 맞춰 손 모양이 어긋나지 않게 했습니다.
- 총구·조준경·손잡이·레이저·탄피 배출 위치 뼈는 새 외형에 맞춰 옮겼습니다.
- 텍스처는 면마다 재질·크기별 사각형을 아틀라스에 배치하고 음영·모서리 하이라이트·나뭇결·홈을 그려 넣습니다.
- 슬롯 아이콘은 기본 팩과 같은 64px 대각선 렌더, HUD 아이콘은 384×128 회색조 옆모습입니다.
- 조합식 재료는 같은 등급 기존 총기의 것을 그대로 씁니다.

## 발사음

기존 TaCZ 음원만 씁니다. 총기마다 음색이 가장 가까운 음원을 기본 발사음(`sounds.shoot` 등)으로 지정하고, 두 번째 음원을 `sound_layers`로 낮은 볼륨·다른 음높이로 겹칩니다. 1인칭·3인칭·소음기 발사음을 각각 따로 지정했습니다. VSS는 소음기 계열 음원만 씁니다.

## 알려진 제약

- 애니메이션은 베이스 총기 것을 씁니다. Win94의 레버 동작은 볼트액션 손동작으로, R1895의 게이트 장전은 실린더를 옆으로 여는 동작으로 대신합니다. Win94는 빈 총 재장전 때 Kar98k의 클립 장전 동작이 나옵니다.
- 개머리판 부착물은 Beryl M762, ACE32, K2, Mk47 Mutant, S12K, Skorpion 6종만 달 수 있습니다. 나머지는 개머리판이 총몸과 한 덩어리입니다.
- 큐브 수는 총기당 35~180개입니다. 기존 수작업 모델(350~760개)보다 단순합니다.
- Gradle 빌드와 게임 실행은 하지 않았습니다. 1인칭 손 위치, 조준 정렬, 부착물 위치, DBS·MG3 특수 동작, 음량은 게임에서 확인해야 합니다.
