# Jobs+

Jobs+는 Minecraft에 직업, 레벨, 스킬, 보상, 아이템 제한, 상점 및 주식 거래 기능을 추가하는 Fabric 모드입니다.

서버 공통 수면·전투·사망·피해·배고픔 규칙은 별도 [Server Utilities](ServerUtilities-26.2/README.md) 모듈에서 관리합니다.
해당 규칙을 유지하려면 이번에 수정한 Jobs+·Advanced Netherite와 Server Utilities를 함께 설치합니다.

## 주요 기능

### 직업 시스템

8개의 직업을 제공합니다.

| 직업 | 주요 활동 |
| --- | --- |
| 모험가 | 걷기, 달리기, 수영, 승마, 겉날개 활공 등 이동 |
| 연금술사 | 양조, 연금술 재료 수집 |
| 굴착공 | 흙과 모래 계열 굴착, 블록 설치 |
| 농부 | 작물 재배, 동물 번식과 길들이기 |
| 낚시꾼 | 낚시, 수영 |
| 사냥꾼 | 생물 처치, 훈연기 조리 |
| 광부 | 석재와 광석 채굴 |
| 대장장이 | 제작, 제련, 마법 부여, 모루와 숫돌 사용 |

플레이어는 직업별 활동을 수행하여 경험치를 얻고 레벨을 올립니다. 직업 레벨과 조건에 따라 새로운 능력, 보상, 아이템 사용 권한이 해제됩니다.

### 스킬 및 파워업

직업마다 10단계로 구성된 스킬 계열을 제공합니다. 스킬은 코인으로 구매하며 요구 레벨을 만족해야 해방됩니다.

같은 계열의 여러 단계를 보유하더라도 가장 높은 단계 하나만 적용됩니다.

스킬이 발동해 추가 아이템이나 경험치를 얻으면 본인 채팅에 알림이 표시됩니다. 스킬 화면 오른쪽 위의 `스킬 알림` 버튼을 누르고 확인 창에서 `네`를 고르면 이 알림을 끄거나 다시 켤 수 있습니다. 설정은 플레이어 데이터에 저장되어 재접속과 사망 뒤에도 유지되며, 스킬 효과와 보상, 비트코인 획득 공지, 레벨업 알림에는 영향을 주지 않습니다.

### 아이템 제한

직업, 레벨 또는 지정된 조건에 따라 다음 행동을 제한할 수 있습니다.

- 아이템 제작
- 제련
- 양조
- 마법 부여
- 모루 및 숫돌 사용
- 아이템 사용
- 블록 설치
- 블록 파괴
- 몬스터 공격

조건을 만족하지 않으면 화면에 제한 사유가 표시됩니다.

### 상점 및 비트코인

아이템 판매와 비트코인 기반 계좌 기능을 제공합니다.

- 인벤토리의 비트코인을 계좌에 입금하거나 출금할 수 있습니다.
- 입출금은 10개 단위로만 가능합니다.
- 출금 시 출금 금액의 0.2%가 세금으로 차감됩니다.
- 계좌 잔액으로 주식을 거래합니다.

### 주식 거래

서버가 확정한 시세 스냅샷 하나를 클라이언트 표와 매수·매도가 함께 사용합니다.

- 시세는 서버 시스템 시간 기준 **매분 00초**에 갱신됩니다.
- 갱신이 끝나기 전과 조회에 실패한 종목은 거래가 중지됩니다.
- 이전 분의 가격으로는 체결되지 않습니다.
- 주식 탭을 보고 있는 플레이어가 있을 때만 시세를 조회합니다.
- 기본(X1) 판매 수수료는 판매 금액의 0.015%이며, 배율 포지션은 수수료에도 같은 배율이 적용됩니다. (예: X10이면 0.150%)

> [!IMPORTANT]
> 클라이언트는 외부 시세 API를 직접 조회하지 않습니다. 화면에 표시되는 가격과 서버에서 실제로 체결되는 가격이 어긋나는 것을 막기 위한 구조입니다.

### 밸런스 분석 메트릭

서버는 `logs/jobsplus-metrics/v2/<시즌>`에 직업 Action별 횟수·EXP·BTC, 레벨업·스킬 구매·쿠폰·관리자 명령·사망(원인과 가해 몹의 무기),
플레이어 상태와 1분 단위 활동·잠수 여부, 적용 중인 보상표를 기록합니다.
기록 형식, 집계 스크립트, 시즌 운영 절차는 [직업 밸런스 메트릭](JobsPlusRemastered-26.2/docs/metrics.md)을 참고하세요.

## 필수 모드

Jobs+를 실행하려면 다음 모드가 필요합니다.

| 라이브러리 | 버전 |
| --- | --- |
| Fabric API | 0.154.2+26.2 이상 |
| Architectury API | 21.0.6 |
| YAML Config | 1.3.2-26.2 |
| UI Lib | 2.1.4-26.2 |
| Arc | 1.9.7-26.2 |
| Item Restrictions | 1.3.4-26.2 |

> Advanced Netherite는 비트코인 아이템과 Jobs+ 연동 기능에 필요합니다. 설치하지 않으면 상점과 주식 기능이 동작하지 않습니다.

## 설치 방법

1. Minecraft 26.2용 Fabric Loader를 설치합니다.
2. Java 25를 사용하도록 실행 환경을 설정합니다.
3. 필수 모드와 Jobs+ Fabric JAR 파일을 `mods` 폴더에 넣습니다.

   ```text
   .minecraft/mods/
   ```

4. 게임 또는 Fabric 서버를 실행합니다.

전용 서버에서도 동일하게 서버의 `mods` 폴더에 Jobs+와 필수 의존성 모드를 모두 설치해야 합니다.

### 운영 서버 업데이트

- Jobs+ `1.6.5-26.2`는 하이퍼 스킬을 포함한 직업 패킷 v2를 사용합니다. 서버와 모든 클라이언트의 Jobs+를 같은 배포 JAR로 함께 교체합니다. 구형 클라이언트는 월드 진입 전에 업데이트 안내와 함께 접속이 거부됩니다.
- 서버를 정상 종료하고 월드·설정·기존 `mods`를 백업한 뒤 JAR을 교체합니다. 같은 mod ID의 구형 JAR을 `mods`에 남기지 않습니다. JAR 변경은 `/reload`로 적용되지 않으므로 서버와 클라이언트를 다시 시작합니다.
- 자석석 설치 기록 복구와 피스톤 이동 추적은 Server Utilities `1.0.1`에 포함됩니다. 기존 설치 기록 파일을 삭제하거나 초기화하지 않습니다.
- 저장소 브랜치 이름은 `26.3`이지만 현재 빌드 대상은 Minecraft `26.2`입니다. 운영 서버의 실제 버전과 일치하는지 먼저 확인합니다.
- 재시작 후 최신 클라이언트의 직업·스킬 화면과 하이퍼 스킬 상태가 정상인지, 구형 클라이언트에는 업데이트 안내가 나오는지 확인합니다.
- 자석석을 설치한 상태에서는 두 번째 설치가 거부되고, 채굴·폭발·명령어 제거 후에는 재설치가 허용되어야 합니다. 일반·끈끈이 피스톤으로 이동한 뒤에도 두 번째 설치는 거부되며, 이동된 자석석을 파괴한 뒤에는 재설치가 허용되어야 합니다.
- 자석석이 있는 청크를 언로드하거나 다른 차원으로 이동한 경우, 두 플레이어의 연속된 자석석을 함께 민 경우, 재접속·서버 재시작 후에도 같은 제한과 복구 동작을 확인합니다.

## 빌드 방법

빌드는 개별 모듈 폴더가 아니라 저장소 루트의 수집 스크립트로만 실행합니다.

```bash
python Build_File-26.2/collect_fabric_jars.py
```

등록된 모든 모드가 순서대로 빌드되고, 배포용 JAR이 `Build_File-26.2/build_files/`에 모입니다.

자세한 내용은 [buildMe.md](buildMe.md)를 참고하십시오.

## 프로젝트 구조

```text
JobsPlusRemastered-26.2
├─ common              공통 게임 로직, 직업, 스킬, 데이터, 네트워크 및 UI 연동
├─ fabric              Fabric 초기화 및 Fabric 배포 JAR 생성
├─ docs                기능 문서
├─ tools/metrics       밸런스 메트릭 집계 스크립트와 회귀 검사
├─ build.gradle
├─ settings.gradle
└─ gradle.properties
```

이 프로젝트는 Fabric 단일 플랫폼입니다. NeoForge 관련 소스와 설정은 모두 제거되었습니다.
