# 총기 도감

`총기 도감` 탭은 현재 로드된 TACZ 팩의 총기·탄약·조준경·파츠를 조회합니다.
카드를 선택하면 아이템 미리보기, 제작 재료와 보유 수량, 호환 항목을 표시합니다.
호환 항목을 누르면 해당 탄약/부품/총기의 분류, 카드와 상세 정보로 이동합니다.

- 모든 분류의 목록은 3열이며 긴 이름은 65% 크기로 줄바꿈합니다.
- 제목 오른쪽 검색창은 이름과 ID를 분류 전체에서 검색합니다. 대소문자·공백은 무시합니다.
  결과 목록은 별도 스크롤을 제공하며, 선택 시 해당 분류·카드 위치·상세로 이동합니다.
  검색창을 다시 선택하면 같은 검색 결과를 다시 볼 수 있습니다.
- 총기에는 피해량, 거리별 피해량, 헤드샷, 방어구 무시율, 탄속, 관통, 연사,
  확장 탄창, 재장전/조준 시간, 반동, 탄퍼짐, 이동 보정, 근접 공격, 과열/충전 등을 표시합니다.
  수치는 로드된 팩의 기본값이며 서버 배율, 현재 장착 효과와 런타임 스크립트 결과는 포함하지 않습니다.
- 파츠는 옵션별 고정 보정·증감률·배율과 조준 배율을 표시합니다. 전용 총기의 대체 옵션도
  총기와 파츠 양쪽에 표시합니다. Lua 함수는 실행하지 않고 조건부 효과임을 안내합니다.
- 제작식 번호와 결과 개수 문구는 숨기고 재료 아이콘·보유/필요 수량을 표시합니다.

- `TimelessAPI`의 클라이언트 인덱스와 동기화된 공통 인덱스를 함께 사용합니다.
- 작업대 제작식은 `getAllRecipes()`에서 읽으며, 같은 결과의 여러 제작식을 모두 표시합니다.
- 재료 아이콘은 `Ingredient.display()`로, 보유 수량은 `Ingredient.test()`와 일반 인벤토리로 계산합니다.
- 파츠는 TACZ의 `allowAttachment()` 판정과 총기 허용 슬롯을 모두 확인합니다.
- 배율은 조준경의 실제 `getZoom()` 값을 사용합니다. 기본 조준 배율과 내장 부품은 별도 표시합니다.
- 숨김 부품은 숨김 상태를 표시합니다. 호환 표시는 개별 총기의 부착물 잠금 해제를 의미하지 않습니다.
- 제작식이 없는 항목에는 임의 재료를 넣지 않습니다. 실제 제작은 TACZ 작업대에서 합니다.
- 팩을 다시 로드한 뒤에는 도감 탭을 다시 열어 최신 목록을 읽습니다.

TACZ는 선택적 연동입니다. JobsPlus에 필수 빌드 의존성을 추가하지 않기 위해 공개 API를
반사 호출하며, 연결 실패 시 안내 문구와 로그를 남깁니다. API 기준은 이 저장소의
`TACZ-Refabricated-26.2`, `26.3` 브랜치입니다. 다른 TACZ 버전과의 호환은 보장하지 않습니다.

## 수동 확인

1. `JobsPlusRemastered-26.2`에서 `./gradlew :fabric:build`로 모드를 빌드합니다.
2. Minecraft 26.2와 해당 TACZ 버전으로 홈 탭의 좌측 정렬, 직업 시작/스킬의 중심선을 확인합니다.
3. 상점 상품이 2열이며 각 카드의 입력 → 출력이 한 줄로 표시되고 선택/스크롤/구매되는지 확인합니다.
4. 주식 탭에 하단 시세 상태 문구가 없고, 종목 선택 및 거래 탭 전환이 유지되는지 확인합니다.
5. 총기 카드의 탄환 링크, 조준경 배율, 호환 파츠 링크, 여러 제작식 및 재료 수량을 작업대와 대조합니다.
6. 검색 결과가 없을 때, 긴 이름, 한글/영문 검색, 결과 스크롤과 선택 후 이동을 확인합니다.
7. GUI 배율을 바꿔 헤더, 상점 구매 버튼, 도감 목록/상세 스크롤의 겹침과 클릭 범위를 확인합니다.
8. TACZ가 없는 환경에서는 도감 안내가 표시되고 다른 JobsPlus 탭이 작동하는지 확인합니다.

공통 Java 소스 컴파일은 수행했습니다. Fabric 전체 빌드와 위 인게임 확인은 수행하지 않았습니다.
